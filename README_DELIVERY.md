# دليل تشغيل نظام نقطة بيع "هيا" (Haya POS) المطور للعميل

مرحباً بك في نظام نقطة البيع المطور! هذا الدليل يوضح لك خطوات تثبيت وتشغيل النظام على جهازك بنجاح.

---

## 1. المتطلبات الأساسية للتشغيل
قبل تشغيل النظام، تأكد من توفر المتطلبات التالية على جهاز العميل:
1. **لغة بايثون (Python 3.10 أو أحدث)**:
   - يجب تحميل وتثبيت بايثون من الموقع الرسمي وتأكيد تفعيل خيار **"Add Python to PATH"** أثناء التثبيت.
2. **المكتبات اللازمة لبايثون**:
   - افتح موجه الأوامر (CMD) وشغّل الأمر التالي لتثبيت المكتبات المطلوبة للاتصال بقاعدة البيانات وسيرفر الـ API:
     ```bash
     pip install fastapi uvicorn pyodbc pydantic
     ```
3. **تعريف الاتصال بقاعدة البيانات**:
   - تأكد من تثبيت **Microsoft ODBC Driver for SQL Server** لربط النظام بقاعدة بيانات SQL Server بنجاح.

---

## 2. خطوات التشغيل
1. قم بفك الضغط عن الملف المضغوط `Haya_POS_Package.zip` في أي مكان تريده على القرص الصلب.
2. للتأكد من بيانات خادم SQL Server واسم قاعدة البيانات والمستخدم، قم بفتح ملف `server_config.json` وتعديلها إذا لزم الأمر:
   ```json
   {
     "server": "S1\\SQLEXPRESS",
     "remote_server": "S1\\SQLEXPRESS",
     "local_db": "sp",
     "remote_db": "sp",
     "username": "sa",
     "password": "as",
     "port": "",
     "point_no": 1,
     "point_name": "الرئيسية"
   }
   ```
3. انقر نقراً مزدوجاً على الملف:
   👉 **`run_pos.bat`**
4. سيقوم الملف بتشغيل خادم الـ API وخادم الويب مصغّرين في الخلفية، ويفتح متصفح الإنترنت الافتراضي لديك تلقائياً على الرابط:
   👉 **http://localhost:8080**

---

## 3. إيقاف التشغيل
لإيقاف تشغيل خوادم النظام بالكامل:
- أغلق نافذة موجه الأوامر السوداء التي تم فتحها، أو قم بإنهاء العمليات مصغرة الحجم من شريط المهام.
